# Fish Utils

A collection of useful Fish shell functions.

## Requirements

- Fish shell

## Installation

git clone https://github.com/KunalKhandelwal1/fish-utils.git
cd fish-utils
./install.fish
If u want proxy :
Update pxy.fish -> port and IP according to your system 

Restart your Fish shell.

## Usage

gitcmd
web
pxy

## Uninstallation

cd fish-utils
./uninstall.fish
